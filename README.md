## Featured projects

### Sentinel Swarm — Multi-Modal Attendance Management System

A full-stack university attendance and access-management project combining a web dashboard with ESP32 and Raspberry Pi devices. The documented system supports fingerprint, RFID, face, voice, QR, and manual attendance workflows, with student/teacher tools, device management, and attendance reporting.

- [CSC2052 coursework repository](https://github.com/MeshanNawod/csc2052-coursework)
- [Sentinel Swarm repository and detailed system documentation](https://github.com/MeshanNawod/csc2052-coursework-archive)
- [Deployment workflow repository](https://github.com/MeshanNawod/smart-attendance-management-system) — currently contains the FTP deployment workflow, not the application source.

### Slurm Cluster Setup & Automation

A set of Bash scripts and a setup generator for configuring an Ubuntu head-and-worker HPC cluster with Slurm, shared storage, Munge, and time synchronization. This repository is a fork; the upstream project and original cluster work are credited in its README.

[Open the fork](https://github.com/MeshanNawod/slurm-cluster-automation) · [Upstream project](https://github.com/sahan-maker/slurm_cluster)

### OSI / TCP-IP Network Simulator

An interactive educational network simulator. Arrange devices, toggle links, and step through a simplified frame path that demonstrates concepts such as ARP, switch MAC learning, router prefix matching, and TTL. It is a visual learning aid, not a full network emulator.

[Explore the simulator](https://github.com/MeshanNawod/osi-tcp-ip-network-simulator)

### Photo Mosaic Generator

A Python tool that recreates an image, MP4 video, or webcam feed from a library of small tile images. Includes tile matching and reuse strategies, adaptive tile sizes for still images, and high-resolution output options.

[Explore the project](https://github.com/MeshanNawod/photo-mosaic-generator)

### Image-to-CMD Text Art

A Python command-line tool that renders images, videos, and webcam input as character-based text art. Supports shade and edge modes, color themes, and saving output as images, video, or text.

[Explore the project](https://github.com/MeshanNawod/Image-to-CMD)
